# Skill: Architecture Analysis

## Name
architecture-analysis

## Version
1.0.0

## Description
Analyze system architecture for design patterns, structural integrity, scalability risks, security concerns, performance bottlenecks, and alignment with enterprise standards. Produces structured assessment reports with improvement recommendations.

## Parameters
- **scope**: Architecture scope to analyze (system-wide, service, module, component)
- **dimensions**: Analysis dimensions (scalability, security, performance, maintainability, cost)
- **standards**: Enterprise architecture standards to validate against
- **depth**: Analysis depth (high-level overview, detailed component analysis, deep-dive)

## Outputs
- Architecture assessment report with findings and severity ratings
- Architecture diagrams (current state and recommended improvements)
- Risk register for identified architectural risks
- Improvement recommendations with priority and effort estimates

## Prerequisites
- Architecture documentation or codebase must be available for analysis
- Enterprise standards must be defined in the active rule context
- Analysis scope and dimensions must be specified in the task packet

## Approved Categories
- 01_EXECUTIVE_LEADERSHIP_AND_GOVERNANCE
- 30_REVIEW_ONLY_SPECIALISTS

## Usage Rules
- Analysis must be evidence-based — all findings must reference specific components or patterns
- Recommendations must be actionable with clear implementation guidance
- Risk ratings must use a consistent severity scale aligned with project standards
