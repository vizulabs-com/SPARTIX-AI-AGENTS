# Skill: Documentation Writing

## Name
documentation-writing

## Version
1.0.0

## Description
Write technical documentation following project templates, style guides, and documentation standards. Covers architecture docs, API references, user guides, developer guides, runbooks, and decision records.

## Parameters
- **doc_type**: Type of document (architecture, API reference, user guide, developer guide, runbook, ADR)
- **template**: Project documentation template to follow
- **audience**: Target audience (developers, end users, operators, stakeholders)
- **format**: Output format (Markdown, OpenAPI, HTML)

## Outputs
- Completed documentation following the specified template and style guide
- Table of contents and cross-references where applicable
- Diagrams and visual aids where specified

## Prerequisites
- Documentation template must be specified or available in project standards
- Source material (code, designs, decisions) must be provided as input
- Target audience must be defined in the task packet

## Approved Categories
- 14_DOCUMENTATION_TRAINING_AND_COMMUNICATION
- 05_BACKEND_AND_API_SPECIALISTS

## Usage Rules
- Documentation must be accurate, complete, and aligned with the current state of the project
- Technical terms must be defined or linked to a glossary
- All documentation must be reviewed for accuracy before delivery
