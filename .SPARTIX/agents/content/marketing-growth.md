## Growth Frameworks

### AARRR (Pirate Metrics)

-	**Acquisition:** How do users find us? Channels, cost per acquisition, channel mix optimization
-	**Activation:** Do users have a great first experience? Time to value, onboarding completion, "aha moment" identification
-	**Retention:** Do users come back? Cohort retention curves, engagement scoring, churn prediction
-	**Revenue:** How do we make money? Pricing strategy, conversion to paid, expansion revenue, LTV
-	**Referral:** Do users tell others? Viral coefficient (k-factor), referral program mechanics, NPS

### Growth Loops

-	**Content Loop:** Create content, rank in search, attract users, users create content
-	**Viral Loop:** User invites others, new users experience value, new users invite others
-	**Paid Loop:** Revenue funds acquisition, new users generate revenue, revenue funds more acquisition
-	**Data Loop:** More users generate more data, better data improves product, better product attracts users
-	Loop modeling: identify the input, the action, the output, and the reinvestment mechanism
-	Measure loop efficiency: conversion rate at each step, cycle time, compounding rate

### Viral Coefficient Modeling

-	k = (invitations per user) x (conversion rate per invitation)
-	k > 1: viral growth (each user brings more than one new user)
-	Branching factor analysis by channel (email, social, direct share)
-	Time-to-invite optimization: reduce friction between value and sharing
-	Viral payloads: what is shared, how it appears to recipients, landing experience

## Search Engine Optimization

### Technical SEO Audit Checklist

- [ ] Site crawlability (robots.txt, XML sitemap, crawl budget)
- [ ] Indexation status (Google Search Console coverage report)
- [ ] Page speed (Core Web Vitals: LCP < 2.5s, FID < 100ms, CLS < 0.1)
- [ ] Mobile-friendliness (responsive design, mobile usability report)
- [ ] HTTPS implementation (no mixed content, proper redirects)
- [ ] URL structure (clean, descriptive, hierarchical)
- [ ] Canonical tags (prevent duplicate content issues)
- [ ] Hreflang tags (multilingual/multiregional sites)
- [ ] Structured data / schema markup validation
- [ ] Internal linking structure and orphan page identification
- [ ] 404 error monitoring and redirect management
- [ ] JavaScript rendering (SSR/SSG for critical content)
- [ ] Log file analysis (crawl patterns and budget waste)

### Keyword Research Process

1. **Seed keywords:** Core product terms and features
2. **Expansion:** Related terms, long-tail variations, questions (People Also Ask)
3. **Competitor gap analysis:** Keywords competitors rank for that we do not
4. **Intent classification:** Informational, navigational, commercial, transactional
5. **Prioritization matrix:** Search volume x keyword difficulty x business relevance
6. **Content mapping:** Assign target keywords to existing or planned pages
7. **Tracking:** Rank tracking, SERP feature monitoring, click-through rate analysis

### Content Optimization

-	Title tags: primary keyword, compelling, under 60 characters
-	Meta descriptions: action-oriented, include keyword, under 155 characters
-	Header hierarchy: H1 (one per page), H2 for sections, H3 for subsections
-	Content depth: comprehensive coverage of topic, E-E-A-T signals
-	Internal linking: contextual links to related pages, pillar/cluster model
-	Image optimization: descriptive file names, alt text, WebP format, lazy loading
-	Content freshness: regular updates, last-modified dates, evergreen optimization

### Schema Markup

-	Organization schema for company identity
-	Product schema for feature pages and pricing
-	FAQ schema for frequently asked questions
-	HowTo schema for tutorial content
-	Article schema for blog posts and documentation
-	BreadcrumbList for navigation context
-	Software Application schema for app/product pages

### Core Web Vitals Optimization

-	**LCP (Largest Contentful Paint):** Optimize hero images, preload critical resources, use CDN
-	**INP (Interaction to Next Paint):** Reduce JavaScript execution time, use web workers, optimize event handlers
-	**CLS (Cumulative Layout Shift):** Set dimensions on images/embeds, use CSS containment, avoid injected content

### Attribution Modeling

-	**Last-click attribution:** Default, simple, biased toward bottom-of-funnel
-	**First-click attribution:** Credits the channel that introduced the user
-	**Linear attribution:** Equal credit to all touchpoints
-	**Time-decay attribution:** More credit to touchpoints closer to conversion
-	**Data-driven attribution:** ML-based, uses actual conversion path data
-	**Multi-touch attribution:** Custom models combining channel and content interactions
-	Choosing a model: align with business maturity, data availability, and decision needs

### Cohort Analysis

-	Define cohorts by: signup date, acquisition channel, first action, plan type
-	Track: retention rate, feature adoption, revenue per user, lifetime value
-	Visualize: retention curves, cohort heat maps, behavioral flow
-	Identify: which cohorts perform best and what differentiates them
-	Act: optimize acquisition to attract more users who resemble best cohorts

### Mixpanel / Amplitude Advanced Usage

-	Predictive analytics: churn prediction, likely-to-convert scoring
-	A/B test result analysis: statistical significance, segment-level effects

## A/B Testing

### Copy Testing Framework

-	**Headlines:** Test value proposition, specificity, urgency, social proof
-	**CTAs:** Test action verb, specificity, first-person vs second-person
-	**Body copy:** Test length, tone, proof points, objection handling
-	**Email subjects:** Test personalization, curiosity, benefit-driven
-	One variable per test; control for all other factors
-	Minimum sample size calculator: effect size, baseline conversion, significance level

### Landing Page Optimization

-	**Above the fold:** Headline, sub-headline, hero image/video, primary CTA
-	**Social proof section:** Logos, testimonials, metrics, case study snippets
-	**Feature/benefit section:** Problem-solution format, visual demonstrations
-	**Objection handling:** FAQ, comparison table, guarantee/risk reversal
-	**Closing CTA:** Reinforced value proposition, urgency, secondary CTA option
-	Test elements: headline, hero image, CTA text, CTA color, social proof type, page length, form fields

### Email Campaign Optimization

-	Subject line testing (open rate impact)
-	Send time optimization by segment
-	Personalization depth (name, behavior, recommendation)
-	Email sequence timing and cadence
-	Plain text vs HTML performance by audience
-	Unsubscribe rate monitoring and list hygiene

### Statistical Significance

-	Minimum detectable effect (MDE): smallest improvement worth detecting
-	Confidence level: 95% standard, 99% for high-stakes decisions
-	Sample size calculation before launch — never "peek" early without correction
-	Sequential testing or Bayesian methods for faster decisions
-	Segmented analysis: overall effect and effect by key segments
-	Document every test: hypothesis, variant descriptions, sample size, duration, results, decision

## Funnel Optimization

### Conversion Rate Optimization (CRO) Process

1. **Measure:** Instrument every step of the funnel
2. **Analyze:** Identify biggest drop-off points
3. **Research:** Qualitative data (surveys, session recordings, heatmaps) to understand why
4. **Hypothesize:** Form testable hypotheses with expected impact
5. **Prioritize:** ICE framework (Impact x Confidence x Ease)
6. **Test:** A/B test the highest-priority hypotheses
7. **Implement:** Roll out winning variants
8. **Repeat:** Continuous iteration

### User Onboarding Flows

-	**Welcome screen:** Personalized greeting, set expectations, single next step
-	**Progressive profiling:** Collect information gradually, not all upfront
-	**Product tour:** Highlight 2-3 key features, interactive not passive
-	**Aha moment acceleration:** Identify the action most correlated with retention, guide users to it
-	**Checklist pattern:** Visual progress indicator, small achievable steps
-	**Empty state design:** Guide users when content areas are empty
-	**Re-engagement:** Email sequences for users who stall at each onboarding step

### Retention Strategies

-	**Habit loop design:** Cue, routine, reward within the product
-	**Email lifecycle campaigns:** Welcome, activation, engagement, win-back
-	**Push notification strategy:** Value-driven, not attention-seeking
-	**Feature discovery:** In-app education for underused features
-	**Community building:** Forums, user groups, events, advocacy programs
-	**Feedback loops:** Regular surveys, NPS measurement, feature request tracking
-	**Churn prevention:** Early warning signals, intervention sequences, exit surveys
