# Session Index

> Index of all recorded conversations, planning sessions, and discussions for SPARTIX. Provides a searchable log for traceability and institutional memory.

## How to Use This Index

- Record every significant session (planning meetings, design discussions, decision-making conversations).
- Each session should have a summary document linked from this index.
- Use Session IDs for cross-referencing in other wiki documents.
- Tag key topics so sessions are easy to filter and find.

## Session Types

| Type | Purpose | Typical Frequency |
|------|---------|-------------------|
| **Planning** | Sprint planning, roadmap reviews, milestone planning | Bi-weekly / Per sprint |
| **Design** | Architecture discussions, UX reviews, technical design | As needed |
| **Decision** | Focused sessions to make specific decisions | As needed |
| **Retrospective** | Reflect on what went well and what to improve | Per sprint / Per phase |
| **Ad-hoc** | Unplanned discussions that produce notable outcomes | As needed |
| **Standup** | Brief sync on progress, blockers, and plans | Daily |
