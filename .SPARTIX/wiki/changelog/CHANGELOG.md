# Changelog

> Master changelog for SPARTIX. All notable changes are documented here, categorized by type and organized by version.

---

## How to Use This Changelog

- Add entries under the `[Unreleased]` section as changes are made.
- When a release is cut, move unreleased entries under a new version heading.
- Use the categories below to classify each entry.
- Each entry should be a single clear sentence describing what changed and why.

---

## Categories

| Category | Usage |
|----------|-------|
| **REQUIREMENT** | New or changed requirements |
| **ARCHITECTURE** | Architectural changes or decisions |
| **FEATURE** | New functionality added |
| **FIX** | Bug fixes |
| **SECURITY** | Security improvements or patches |
| **PERFORMANCE** | Performance optimizations |
| **SCOPE** | Scope changes (additions or removals) |
| **DECISION** | Significant project decisions |
| **RISK** | Risk-related changes or mitigations |
| **INCIDENT** | Production incidents and resolutions |
| **PIVOT** | Strategic direction changes |
| **DEBT** | Technical debt introduced or resolved |
| **DEPENDENCY** | Dependency additions, removals, or updates |
