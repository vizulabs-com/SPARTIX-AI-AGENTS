## How to Use This Wiki

1. **Finding information** -- Start with the section links above or use the Quick Links for common destinations.

3. **Cross-referencing** -- Link related items across sections (e.g., decisions to ADRs, incidents to lessons learned).
4. **Keeping it current** -- Update the [Project Status](project/status.md) and [Changelog](changelog/CHANGELOG.md) as changes happen.
