# Decision Log

> Chronological record of all significant decisions made during the SPARTIX project. For architectural decisions, see also the [ADR directory](../architecture/adr/).

---

## How to Use This Log

- Record every decision that affects scope, architecture, timeline, resources, or process.
- Include enough context so that someone reading this months later understands why the decision was made.
- Link to ADRs for architectural decisions.
- Decisions are numbered sequentially and never renumbered.

## Decision Categories

Use these categories to tag decisions for easier filtering:

| Category | Description |
|----------|-------------|
| **Architecture** | System design, technology choices, structural decisions |
| **Scope** | Feature inclusion/exclusion, priority changes |
| **Process** | Workflow, methodology, team practices |
| **Timeline** | Schedule changes, milestone adjustments |
| **Resources** | Team changes, tooling, budget |
| **Risk** | Risk acceptance, mitigation strategy changes |
| **Policy** | Standards, conventions, governance rules |
